# TalkToAgent：Stitch 深色原生 UI 還原規格

狀態：**需求已收斂，待實作與驗收。** 本次只建立本地規格，不發布 GitHub Issue、不修改 App 程式碼。

## 目標與依據

將設計師提供的語音主頁盡量還原到 Android 原生 App，並將同一套視覺延伸至全部 App 自有畫面。還原版面與視覺，不複製示範資料或不存在的功能。

來源優先順序：

1. [screen.png](../stitch_talktoagent/screen.png)：主頁外觀、配色、比例、資訊層級的首要基準。
2. [code.html](../stitch_talktoagent/code.html)：補充元件結構及狀態轉場；本規格列出的互動與資料取捨優先於 HTML 示範。
3. [DESIGN.md](../stitch_talktoagent/DESIGN.md)：補充沒有畫稿的頁面及狀態；與實際畫面不同時，以畫面為準。
4. [CONTEXT.md](../CONTEXT.md)：領域詞彙的唯一來源。

### 與既有規格的界線

本規格取代 [Minimalist C 版規格](spec-minimalist-ui.md) 中的灰階外觀、下半部整片主觸控區、全寬取消列及最近定稿預設隱藏的配置，改用設計稿的卡片、圓形麥克風、取消膠囊與首頁定稿摘要。

其餘語音生命週期、期限、觸覺回饋、亮屏、離開／取消、單次提交與結果不明等行為，沿用該規格及目前正式實作。連線／授權仍遵循 [藍牙決策](adr/0001-direct-bluetooth-input.md)、[QR 授權決策](adr/0002-qr-persistent-authorization.md) 與 [QR 驗收](qr-acceptance.md)。本次是可逆的 UI 改造，不新增 ADR。

## 已定案範圍

- 全 App 自有畫面使用設計稿的深色風格，包含連線、設定、金鑰、權限說明、最近定稿及診斷；系統權限與系統藍牙配對畫面維持系統介面。
- 語音僅保留點按：開始 → 再點結束 → 等待轉錄定稿 → 傳送一次。移除按住說話及模式切換入口。
- 接入真實辨識預覽與麥克風音量；電腦仍只接收轉錄定稿。
- 移除頭像及帳號入口，不以其他新入口填補。
- 保留有用途且有真實來源的資訊，刪除假延遲、目標程式／游標偵測、WebRTC、48 kHz、降噪、雙向加強等示範資訊。
- 保留全部既有連線、應用授權、金鑰、權限、定稿複製及診斷／手動測試能力。

本次不包含 Windows Receiver 修改、傳輸／授權協定變更、帳號、持久逐字稿歷史、背景收音、預覽文字編輯、額外送出確認頁或新平台布局。沿用既有直向主畫面範圍；小螢幕、大字體及較寬視窗須可用，不照搬 DESIGN.md 的桌面儀表板。

## 視覺與原生實作

- 還原深藍底、分層卡片、薄荷綠／青色重點、圓角、圖示、文字層級、麥克風漸層與柔和光暈。移除的元素不保留空殼，調整間距維持視覺平衡。
- 不因系統淺色模式或桌布動態色改變本次指定配色。色彩、字級、圓角及間距集中為共用樣式，次頁沿用同一來源。
- 以原生 Android UI 落地，不以 WebView 載入 HTML。沿用目前 Views／Material Components，不要求遷移 Compose。
- 截圖的像素是外觀參考，實作使用 dp／sp 與安全區；不把整張圖固定成一個尺寸。
- 字體與圖示盡量貼近來源。需要的資產在確認授權後隨 App 打包，保留授權資訊；缺少可用素材時以本地向量或合適字體替代，交付時列出差異。正式介面不依賴 Google Fonts、Tailwind CDN 或外部圖片即時載入。
- 主要操作至少保有 48dp 觸控目標，圖示操作有可讀名稱；狀態同時使用文字與色彩。
- 轉場與光暈以辨識狀態為目的，遵循系統動畫設定；離開畫面後停止更新動畫。

## 畫面與資訊架構

### 語音首頁

由上而下維持以下層級：

| 區域 | 內容與操作 |
|---|---|
| 頂部列 | 品牌圖示、TalkToAgent、Voice Input、真實連線標記、設定入口；無頭像。連線標記不代表整體輸入就緒。 |
| 狀態卡 | 實際電腦／未連線狀態、整體就緒條件、本次語音階段、必要阻塞原因與修復入口；通道只顯示已知的藍牙／Wi-Fi。準備與收音時顯示剩餘期限，不保留假延遲徽章。 |
| 文字卡 | 未進行語音時顯示最近一段轉錄定稿摘要及查看／複製入口；進行語音時切換為本次辨識預覽或等待提示。無資料時顯示空態，不放示範句。 |
| 音量區 | 保留稿中的波形構圖，只有實際收音時呈現真實音量；其他階段靜止並顯示對應提示。 |
| 語音操作區 | 大型圓形麥克風／停止按鈕、明確操作提示、獨立取消膠囊。取消不可用時保留位置並顯示停用。沒有模式切換文字。 |
| 底部分頁 | 語音輸入、裝置連線。第二頁沿用稿中的裝置圖示與版位，名稱改為「裝置連線」，內容區分應用授權與系統藍牙配對。 |

最近轉錄定稿不等於最近成功送出。僅顯示可對應到該筆操作的結果；沒有結果資料時不推定成功，不顯示「已送達」或虛構「幾分鐘前」。辨識預覽、語音定稿與手動測試結果分開處理，手動測試不得冒充新的語音定稿。

### 裝置連線與次要頁面

- 裝置連線保留 QR 邀請掃描、恢復既有應用授權、藍牙／Wi-Fi 通道選擇、主動中斷及目前操作回饋；不新增手動 IP／永久配對碼入口。
- 設定入口保留「Gemini 金鑰」「麥克風權限」「診斷／手動測試」。低頻功能不擠回語音首頁。
- 定稿全文與手動複製仍可使用；摘要過長時由詳情承接，不以複製或查看觸發重送。
- 金鑰欄位維持遮蔽，已儲存金鑰不回填到畫面。狀態刷新不清空正在輸入的金鑰或診斷草稿。
- QR 掃描畫面的 App 自有說明／按鈕同樣套用風格，保留既有掃描與授權流程。
- 尚未連線、缺金鑰、缺麥克風權限、連線／辨識失敗等狀態均有原因與可採取的下一步；不是只有停用麥克風。
- 準備、收音、等待定稿、傳送期間停用次要頁面入口，讓結束／取消與本次狀態保持可見。

## 語音狀態呈現

下表是既有生命週期在新畫面上的映射，不是新的獨立狀態機。最近操作結果與目前是否就緒分別呈現。

| 階段 | 主操作 | 取消 | 呈現要求 |
|---|---|---|---|
| 尚未就緒 | 停用 | 停用 | 顯示阻塞原因與修復入口；波形靜止。 |
| 輸入就緒 | 開始 | 停用 | 綠色就緒提示；尚未收音，不顯示活躍音量。 |
| 準備中 | 停用 | 可用 | 說明尚未收音、顯示剩餘期限；不提前播放收音波形。 |
| 收音中 | 結束並送出 | 可用 | 麥克風切為停止圖示，顯示真實音量、辨識預覽及剩餘期限。 |
| 等待轉錄定稿 | 停用 | 停用 | 波形停止，預覽仍標示未定稿；沒有預覽時顯示等待提示。 |
| 傳送中 | 停用 | 停用 | 顯示正在傳送，不能暗示此時可以撤回貼上。 |
| 貼上操作完成 | 依實際就緒條件 | 停用 | 使用領域定義，不聲稱目標程式已接受文字；不以計時器強制恢復就緒。 |
| 已取消／辨識失敗 | 依實際就緒條件 | 停用 | 顯示取消或真實失敗原因，清除本次預覽；保留先前可用的定稿。 |
| 輸入結果不明 | 依實際就緒條件 | 停用 | 提示檢查電腦，不自動重送；沿用既有警告保留規則。 |

期限延續既有包含準備時間的 45 秒，不把剩餘期限改稱已錄音時長。到限、輕震、亮屏、初始化／定稿等待失敗與離開行為，依既有 C 版規格驗收。

## 真實辨識預覽與音量

### 辨識預覽

- 取用辨識服務實際提供的暫定文字，標示「辨識預覽 · 尚未送出」。與定稿的視覺層級有別，不標示為即時貼入電腦。
- 服務沒有提供片段時顯示「等待辨識文字」，不以範例句或假打字動畫填補。
- 片段如何替換或合併須依服務實際回傳語意；不假設每次回呼都是完整句或增量。以代表性回呼序列驗證，不任意重複拼接。
- 點結束後仍等待既有定稿流程；有預覽但沒有有效定稿時不能傳送預覽充數。
- 取消、失敗或未送出即離開後清除本次預覽；不把暫定文字寫入最近定稿、持久歷史或診斷紀錄。
- 新段開始時清空上一段預覽。舊段晚回呼不得覆蓋新段畫面或觸發傳送。

### 音量波形

- 從既有麥克風取樣衍生顯示用音量，不為了波形再開一個錄音來源，也不改變送往辨識服務的音訊。
- 接近設計稿的 32 條圓角波形及綠／青色層次；波形表示實際音量趨勢，不宣稱為精確分頻頻譜或經校準的分貝儀。
- 準備中、待機、停止、取消、失敗及離開時停止活躍波形。收音中拿不到有效音量資料時，顯示不可用／靜止狀態，不產生隨機音量。
- 高頻音量回報只更新波形區，避免整頁反覆重建、抖動或打斷觸控；與預覽相同，回報必須屬於目前有效語音工作階段。

## 版面與可及性

- 主操作、取消及底部分頁位於系統導覽安全區上方；畫面考慮狀態列、挖孔與鍵盤。
- 基準尺寸貼近截圖構圖；小高度或大字體時優先壓縮裝飾與留白，讓資訊區捲動，結束／取消仍直接可見。
- 長電腦名稱與長定稿可截短摘要並提供完整內容；必要操作、阻塞原因與結果不明警告須有完整可讀的呈現方式。
- 設定／診斷可捲動，鍵盤彈出時欄位與提交操作可到達；較寬視窗限制內容寬度，避免卡片與文字無限拉伸。
- 明暗層次及狀態不只依賴顏色。TalkBack 能辨識麥克風操作、取消、設定、分頁及修復入口；持續變動的預覽／音量不造成無休止朗讀。

## 實作切入點

以下是導航指標，不要求保留私有實作形狀。擴充既有呈現契約，避免在新 UI 另寫一套語音或連線流程。

| 檔案／區域 | 本次責任 |
|---|---|
| `app/src/main/java/com/example/talktoagent/NativeCScreen.java` | 原生版面、主／次頁、共用元件、狀態映射及事件；沿用 `State`／`Event` 邊界。 |
| `app/src/main/java/com/example/talktoagent/MainActivity.java` | 將真實連線、辨識預覽與音量接到呈現層，隔離過期回呼；維持現有行為協調。 |
| `app/src/main/java/com/example/talktoagent/GeminiLiveTranscriber.java` | 使用既有暫定文字回報，新增顯示用音量回報；不改定稿與傳輸語意。 |
| `app/src/main/res/` | 共用深色主題、圖示、色彩、字體及元件樣式。 |
| `app/src/main/java/com/example/talktoagent/InvitationScanActivity.java` | 僅調整 App 自有掃描介面外觀，保留流程。 |
| `app/src/test/`、`app/src/androidTest/` | 延伸既有行為及原生畫面測試，加入預覽／音量與視覺狀態覆蓋。 |

## 驗收與交付

### 視覺

- [ ] 主頁截圖能逐區對照來源：頂部列、狀態卡、文字卡、波形、圓形麥克風、取消膠囊、底部分頁。僅本規格核准刪除的內容及必要原生安全區有差異。
- [ ] 連線、設定、金鑰、權限說明、定稿、診斷及 QR 掃描自有介面使用一致風格；系統淺色模式下 App 仍保持指定深色。
- [ ] 不含頭像、模式切換、假數值、示範文字及不受支援的能力宣稱。
- [ ] 在接近設計稿 390×822 比例的手機視窗留存截圖；另檢查 320dp 寬的小可用視窗、系統字體 2.0 倍、長文字、鍵盤、手勢與三鍵導覽。縮放不遮擋主要控制。
- [ ] 留存尚未就緒、就緒、準備、收音、等待定稿、傳送、完成、取消、失敗、結果不明，以及連線／設定代表畫面。測試資料只用於測試，不進入正式執行路徑。

### 行為

- [ ] 點按開始／結束及取消接到正式語音流程；既有 C 版的期限、離開、晚回呼與單次提交驗收沒有退步。
- [ ] 辨識預覽來自本次服務回報；無片段、文字修訂、停止後等定稿、取消後晚回呼及新舊段交錯均有測試。
- [ ] 電腦只收到有效轉錄定稿，預覽顯示或複製不觸發傳送；失敗／結果不明不自動重試或重送。
- [ ] 真實音量驅動波形，且不改動辨識音訊；待機、停止、取消、失敗、離開及舊段回報均不保持活躍波形。
- [ ] 最近定稿與其操作結果不錯配；空態、取消後保留先前定稿、手動測試不覆蓋語音定稿均正確。
- [ ] 原有連線、授權、通道、金鑰、權限、複製與手動測試入口均可操作；重繪不清空輸入草稿。
- [ ] 升級保留既有設定與憑證，不要求清除資料或卸載。Wi-Fi 單次連線與藍牙工作階段行為未因 UI 改版改變。

### 驗證證據

1. 執行既有單元、原生畫面／整合測試及建置、lint，補上本次新增行為的測試。既有入口包含 `NativeCScreenTest`、`NativeCProductionTest`、`ConnectionLifecycleUiTest`。
2. 原生 App 截圖與設計稿並列檢查，列出有意差異及尚未達成的部分；HTML 預覽不能代替原生還原驗收。
3. 實機檢查真實收音、預覽、音量、停止／取消與 Windows 貼上；mock 與模擬器只證明各自覆蓋的範圍。
4. 最終交付列出修改檔案、建置／測試結果、截圖位置，以及未實測或環境阻擋項目。建置成功不等於上述驗收全部完成。
