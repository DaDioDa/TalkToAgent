# TalkToAgent 操作原型（可丟棄）

問題：左手持手機、看著電腦時，哪一種下方主操作最清楚、容易點到，且不易誤取消？

這是已核准的三種灰階網頁模擬，**不是 Android 實作**。沒有既有網頁路由，因此獨立放在文件旁；不增加框架或建置相依。尚未選定方案，不代表已驗證設計。正式 App 的按住說話行為完全不變。

## 開啟

直接雙擊本目錄 `index.html`，或在 repository 根目錄用 PowerShell / Command Prompt 執行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory docs/prototype/uiux
```

- A：[下方大圓鈕](http://localhost:8765/?variant=A) — 熟悉的圓形目標，取消在右下角；比較拇指移動距離。
- B：[底部操作列](http://localhost:8765/?variant=B) — 寬主按鈕與右側獨立取消區；比較短距離與誤取消。
- C：[下半部觸控區](http://localhost:8765/?variant=C) — 大面積下半部目標，右下角另留取消區；比較不看螢幕定位與握持誤觸。

下方浮動「比較原型」列不屬於 App，左右箭頭循環切換，URL 保留版本。鍵盤左右箭頭也可切換，但不攔截輸入欄位或面板中的按鍵。切換保留操作狀態，方便同條件比較。

### 用手機比較

先用 loopback 預覽；若要手機開啟，請自行在可信私人網路上重新執行：

```powershell
python -m http.server 8765 --bind 0.0.0.0 --directory docs/prototype/uiux
ipconfig
```

手機與電腦需在同一可互通網路，以電腦有效網卡的 IPv4 開啟 `http://<電腦 IPv4>:8765/?variant=A`（或 B/C）。此命令會讓網路上的其他裝置可存取本目錄，不要在公共網路使用。防火牆可能阻擋，原型不會修改規則。結束按 Ctrl+C。不提供未驗證的 LAN 地址。

## 確認過的設計方向

- 極簡是清楚、直接，不為減少按鈕而增加步驟。常用操作可見，低頻設定與診斷收起。
- 點一下開始錄音、再點一下結束。轉錄定稿後自動送往電腦，沒有日常確認步驟。
- 主操作位置固定；右下角取消僅丟棄本次錄音，不能撤回已發出的貼上。
- 開始 / 結束有文字輕震提示，可在原型控制台選擇嘗試瀏覽器震動；沒有提示音。
- 一台固定電腦，上方精簡連線入口開啟管理面板。不是常駐配對或通道選擇畫面。
- 最近轉錄平時隱藏，按明確次要入口查看；只有記憶體內的最近一段，無歷史。
- 手動文字輸入僅在「設定 → 診斷與手動測試」，不是主畫面操作。
- 定稿 / 傳送時禁止重複開始或送出。輸入結果不明時請看電腦，不自動重送。

## 建議比較流程

1. 三版各點主操作開始 → 結束；觀察輕震文字、定稿、傳送、貼上操作完成。
2. 再開始 → 右下取消；查看最近轉錄，確認沒有新增定稿。
3. 展開 App 外的「原型控制台」，改下一次結果為「輸入結果不明」或「傳送期間斷線」；開始 / 結束，確認警告與不重送。
4. 「模擬斷線」→ 上方電腦名稱 → 模擬重新連線。傳送期間斷線保留結果不明警告。
5. 設定 → 診斷，輸入測試文字；處理中不可重複傳送。重設模擬會清空最近轉錄並回到就緒。
6. 在錄音 / 傳送時切換版本，比較主操作位置、左手伸距及取消區隔；控制台顯示完整相關狀態。

## 邊界與驗證

所有結果均為計時器與範例文字模擬。不使用真正麥克風、Gemini、憑證、receiver 流量、電腦剪貼簿或持久儲存。「貼上操作完成」只表示電腦發出貼上操作，**不保證目標程式接受文字**。無自動重送與撤回功能。

瀏覽器震動支援、原生輕震、實際手機單手伸距與握持誤觸仍需實機驗證；桌面模擬不能證明這些體驗。短螢幕可捲動頁面，比較工具與 App 以外框與標籤區隔。

這是 throwaway UI，不建立正式單元測試套件；以 JS 語法 / 型別檢查和瀏覽器操作 smoke check 驗證。選出方案後再依正式 App 的邊界做 TDD，不直接把此模擬程式搬進產品。版面選擇尚未定案，因此不改 `CONTEXT.md`，也不建立 ADR。
