# 跨裝置語音輸入：家庭網路原型範圍

## 目標與驗收

- 目標裝置：已連接實機 SM-F7410（Android API 36）；第一版只保證支援此手機。
- 手機按住說話、放開結束本次語音；使用 Gemini 3.5 Transcribe Live 的 SMART 模式。手機可以顯示辨識過程，但只將**轉錄定稿**送往電腦；中文輸出必須為繁體字形，若模型未輸出繁體，需轉換後才送出。第一版不要求台灣慣用詞轉換。
- Windows Python Receiver 將收到的文字寫入剪貼簿，對**貼上瞬間的焦點**模擬 Ctrl+V。允許覆蓋原剪貼簿，不還原；不額外送出空格或換行。先以一般文字編輯器和瀏覽器輸入框驗收，不保證所有視窗（尤其管理員視窗、終端機等）都適用。
- 若辨識或傳送失敗，手機顯示錯誤，不自動重送；畫面暫留最近一段文字供查看或手動複製，退出後不保留歷史。貼錯焦點不自動回復。

## 操作與系統邊界

- 手機與電腦位於可互通的同一私人區域網路；Windows 提供 IP、埠與配對碼，由手機手動設定。Receiver 僅接受已驗證的連線，限制可接收的訊息大小。
- 手機左上角為單一連線燈號：Windows 已驗證連線、且 Gemini 啟動的必要條件具備時才顯示「輸入就緒」；任一已知條件失效時不得顯示就緒。Gemini Live 只在按下說話時連線，因此**閒置時綠燈不代表 Gemini 已連線，也不保證下一次辨識成功**；介面須提供文字狀態／錯誤原因。
- 個人自用原型由使用者手動在手機設定 Gemini API key；不寫入原始碼、Git 或 APK 內建常數。Windows Receiver 不代理 Gemini，也不持有此 key。
- Android 的辨識流程與文字傳送分離；Windows 的接收與貼上分離。傳輸設計可插拔且預留 BluetoothTransport，但第一版僅實作 WebSocketTransport；不把 Gemini 的暫定辨識片段當作可貼上訊息。
- 家庭網路原型採未加密 `ws://` 搭配配對碼，**不是辦公室安全版本**：配對碼與轉錄文字可能被同網路竊聽。在辦公室網路部署前須重新設計／加入加密通道與憑證處理，不應直接拿這版傳敏感文字。

## 不在第一版

- 藍牙實作、區網自動發現、QR 配對、多裝置、背景常駐收音、剪貼簿還原、逐字稿歷史、暫定稿即時改寫、斷線自動補貼、辦公室部署。

## 主要待驗證風險

- 實機按住／放開時 Gemini Live 是否穩定給出一段定稿、SMART 模式輸出的文字是否需要繁簡轉換；Live session 上限與費用依使用情形另行評估。
- 中文、英文混合與標點的貼上表現；放開前後焦點切換、貼上失敗以及剪貼簿被其他程式同時改寫的狀況需實測。
- 「已送達」不等於「文字確實出現在目標程式」；若之後需要強一致確認與去重，必須另外定義接收確認協定。
