# QR／持久授權實機驗收

來源 #9／#10。自動協定測試、編譯成功與下列硬體驗收分別記錄。不要將已配對藍牙的一次舊版貼上視為新流程通過。操作需使用者確認系統配對及目標文字欄位；不能繞過系統提示。

## 執行紀錄

- 狀態：待實機驗收。
- 裝置：SM-F7410、實際 Windows radio／驅動、Windows 終端。
- 每次記錄 App／Receiver commit、OS／終端／字型／缩放、操作步驟及實際結果。
- 本機 API smoke 已驗證：user-scoped DPAPI 往返、列舉單一實體 radio、同址安全 RFCOMM bind 及 SDP 註冊／移除。測試沒有 accept 客戶端或執行貼上；不能視為掃碼、系統配對、Android Keystore 或手機互通驗收。
- 不附邀請 QR、秘密或授權資料；截圖需遮蔽敏感區域。不要將含 QR 的主控台輸出保存為一般日誌。

## 清單

- [ ] Wi-Fi 選單目的位址，App 內掃碼直接取得應用授權，无手動資料入口／額外目標確認。
- [ ] 藍牙從未配對狀態掃碼，兩端系統確認後等待指定裝置 BOND_BONDED，自動續接安全 RFCOMM；無主控台 yes。
- [ ] 取消系統配對停止嘗試並要求重掃；失敗不降級 insecure RFCOMM。
- [ ] 系統配對完成後邀請已過期，提示 Windows 產生新邀請，不解除系統配對。
- [ ] 真實 URI 長度在目前終端可掃描，包含字型、縮放、深淺背景及四周空白；太窄有調整及重顯示導引。
- [ ] show 不延長期限；new 使舊 QR 失效；邀請成功後不能再次首次授權。
- [ ] 同手機分别追加 Wi-Fi／藍牙，未扫通道无權限；其他手機即使持新邀請亦被拒絕直到撤銷。
- [ ] App 與 Receiver 分別／同时重啟后原授權保留，按連線恢复；冷啟動不自動連線。
- [ ] 授權成功回覆中途斷線，原手機可恢复；第二手機不可使用原邀請；沒有文字補送。
- [ ] 已連線／口述中不能掃新邀請；中斷未知結果保留「輸入結果不明」。
- [ ] 藍牙短斷線工作階段可退避重連；通知中斷後不重連。另核對原本 30 分鐘鎖屏要求，不將短斷線当作長時間保活證據。
- [ ] revoke 即時終止現有連線，两通道舊授權／重連不可貼上，新手機需新邀請。
- [ ] Windows 鎖定時拒絕新輸入，解鎖後按流程恢復，不補送。
- [ ] IP 改變，原手機掃新更新邀請核對雙方身分，成功更新；非法／不同 Receiver QR 不污染原目標。
- [ ] 相機／附近裝置／通知權限拒絕、永久拒絕、無camera、藍牙關閉及目標不可達都有修復提示且不顯示「輸入就緒」。
- [ ] 多／單／無 radio 符合選擇與阻止啟動契約，QR／SDP／listener 對应同一實體介面。
- [ ] 繁體與英文混合定稿只貼一次，不加 Enter；確認「貼上操作完成」文字不誤稱目標接受或執行。

未通過項目須記錄平台限制及下一步；保持 issue 開啟，不默默放寬安全契約。
