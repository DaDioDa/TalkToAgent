# 01: 還原語音首頁與既有操作

**What to build:** 使用者開啟 Android App，即可在貼近設計師截圖的深色原生首頁查看真實連線與輸入狀態，點按開始說話、再次點按結束，或取消本次輸入。最近轉錄定稿及次要功能入口仍可使用；新版畫面接到正式語音流程，而不是可點擊的示範稿。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

## 規格界線

依《TalkToAgent：Stitch 深色原生 UI 還原規格》的「視覺與原生實作」「語音首頁」「語音狀態呈現」「版面與可及性」實作；來源與領域文件由本功能索引提供。設計師截圖優先於互動稿及設計系統描述，本規格核准的刪除與文案調整優先於示範內容。

先在既有原生呈現邊界內整理必要的共用樣式與元件，保持行為測試可通過，再完成首頁。此整理併在本票內，不另建語音狀態機或遷移 UI 框架。

本票保留文字卡及音量區的構圖，但尚不接入新資料能力：活動期間顯示階段／等待提示與靜止波形，不放假文字或隨機音量。真實辨識預覽與音量由後續票完成。次頁先保留可操作的既有內容，完整視覺延伸由另一張票承接。

## Acceptance criteria

### 首頁與入口

- [ ] 以原生 UI 還原深藍底、綠／青重點、卡片、字體層級、圓角、麥克風漸層與光暈；頂部列、狀態卡、文字卡、音量區、語音操作及底部分頁的層級貼近畫稿。色彩與元件樣式可供次頁共用，系統淺色模式或動態色不改變指定深色。
- [ ] 移除頭像、帳號入口、按住說話及模式切換，以及假延遲、目標程式／游標偵測、WebRTC、48 kHz、降噪與雙向加強等示範資訊；移除後調整間距，不留下無用空殼。
- [ ] 顯示真實電腦／未連線狀態及已知通道，將連線標記與整體輸入就緒分開。缺金鑰、缺麥克風權限、未驗證或已知故障均有可理解的原因及可用修復入口。
- [ ] 底部分頁為「語音輸入」「裝置連線」，頂部設定入口可達既有設定。連線、授權、金鑰、權限、診斷／手動測試及定稿查看／複製能力均仍可操作，沒有空的導覽終點。
- [ ] 文字卡正確呈現空態或最近一段轉錄定稿摘要；長文可查看完整內容並手動複製。查看／複製不重送，無持久歷史、範例句、假時間或未經確認的成功標記。手動測試不覆蓋語音定稿，其結果也不附到錯誤的定稿上。

### 正式語音流程

- [ ] 單次點按開始，真正收音後才提示可以說話；再點按結束，等待有效轉錄定稿後最多傳送一次。沒有長按要求、預覽編輯或例行確認頁。
- [ ] 尚未就緒、就緒、準備、收音、等待定稿、傳送、完成、取消、失敗、結果不明均映射到真實狀態，主操作／取消／次要入口的可用性符合規格。準備與收音可取消；等待定稿及傳送中不提供可撤回的假象。
- [ ] 保留包含準備時間的 45 秒期限、剩餘時間、到限收尾及既有輕震／亮屏行為；剩餘期限不標示為已錄音時間。取消、離開、失敗與晚回呼仍依既有生命週期處理，沒有重複提交或取消後傳送。
- [ ] 完成顯示「貼上操作完成」，不保證目標程式接受文字；「輸入結果不明」提示檢查電腦，沿用警告保留規則。成功或計時器到期均不強制恢復就緒，失敗與結果不明不自動重試／重送。
- [ ] 升級保留設定與憑證；傳輸、應用授權、Wi-Fi 單次連線及藍牙工作階段行為不變，不修改 Windows Receiver。

### 可及性與驗證

- [ ] 主操作、獨立取消膠囊及底部分頁避開系統安全區；取消停用時保留位置。在 320dp 寬、小可用高度、2.0 倍字體及長文字下，結束／取消直接可見，必要狀態可完整閱讀。較寬視窗限制內容寬度。
- [ ] 操作至少有 48dp 觸控目標、可讀的 TalkBack 名稱，狀態不只靠顏色。裝飾動畫遵循系統設定，離開後停止；本票的靜止波形不聲稱正在測量音量。
- [ ] 字體、圖示與品牌素材隨 App 本地提供，新增素材確認並保留授權；不依賴外部圖片或字體即時載入。無法完全還原的素材替代記錄在交付差異中。
- [ ] 補上首頁狀態、點按／取消、修復入口、定稿與結果對應及導覽的回歸測試；執行相關單元、原生整合測試、建置及 lint，既有語音生命週期測試保持通過。
- [ ] 留存上述全部語音狀態的原生截圖，在接近 390×822 比例的手機視窗與設計稿並列檢查；另記錄小視窗、大字體、長文字及手勢／三鍵導覽結果。清楚標明本票尚未接入的即時資料，而不是以假資料通過比對。
- [ ] 以正式 App 驗證語音輸入、停止／取消與電腦貼上；交付測試結果、截圖、視覺差異及未實測項目。環境阻擋維持待驗收，不以 HTML 預覽、mock 或建置成功冒充真機驗證。
