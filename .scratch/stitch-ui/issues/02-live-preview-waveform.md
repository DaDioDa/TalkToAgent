# 02: 接入真實辨識預覽與音量波形

**What to build:** 使用者在新版首頁說話時，看得到本次語音辨識服務提供的辨識預覽，以及隨真實麥克風音量變化的波形。點按結束後仍等待轉錄定稿才傳送；取消或離開不留下錯誤的活動畫面，也不讓舊段回報污染下一段。

**Blocked by:** 01 — 還原語音首頁與既有操作。

**Status:** implementation-complete（human-validation-pending）

## 規格界線

依《TalkToAgent：Stitch 深色原生 UI 還原規格》的「真實辨識預覽與音量」「語音狀態呈現」及首頁視覺要求實作；來源與領域文件由本功能索引提供。

本票完成服務／麥克風資料到正式首頁的完整路徑，沿用前置票的卡片、操作及狀態呈現。擴充既有呈現與回報邊界，不以測試專用平行流程代替正式接線。

辨識預覽不是轉錄定稿，也不表示已送往電腦。本票不新增預覽編輯、額外確認步驟、長按模式、持久歷史、背景收音或 Windows 功能，不更改既有定稿、傳輸與授權語意。

## Acceptance criteria

### 辨識預覽

- [x] 真正收音期間，文字卡使用本次辨識服務回傳的暫定文字，標示「辨識預覽 · 尚未送出」，與最近轉錄定稿有清楚視覺區別。服務沒有提供片段時顯示「等待辨識文字」，不用範例句、假打字或上一段文字填補。
- [x] 依服務實際回傳語意處理文字替換、修訂或增量；以代表性回呼序列驗證，避免重複拼接、遺失修訂或把完整快照當成新增片段。
- [x] 點按結束後顯示等待轉錄定稿；可保留本次預覽但仍明示未定稿、未送出。有預覽而沒有有效定稿時，不使用預覽充數傳送。
- [x] 有效轉錄定稿仍經既有驗證及收尾流程最多傳送一次，成為最近定稿；完成／失敗／結果不明仍對應實際操作結果。預覽更新不觸發傳送，也不改變最近定稿的來源。
- [x] 取消、失敗或未送出即離開後清除本次預覽，保留先前可用的定稿；開始新段時清空舊預覽。暫定文字不寫入持久歷史、診斷紀錄或已定稿欄位。
- [x] 過期或已取消語音段的辨識回報不能恢復活動畫面、覆蓋新段文字或觸發傳送；停止後、等待定稿中及新舊段交錯的回報只依有效語音階段處理。

### 真實音量

- [x] 從既有麥克風取樣衍生顯示用音量，不另開錄音來源、不改動送往辨識服務的音訊。波形接近畫稿的 32 條圓角綠／青構圖，表示實際音量趨勢，不宣稱分頻頻譜或校準分貝值。
- [x] 只有本次實際收音時才呈現活躍音量；待機與準備中不提前動作，停止、取消、失敗及離開立即停止活躍波形。缺少有效音量時顯示靜止／不可用狀態，不產生隨機訊號。
- [x] 舊段或已結束階段的音量回報不重新啟動波形；靜音、不同音量、無資料及階段切換都有可重現的驗證案例。
- [x] 音量高頻更新只影響必要的波形區域，不造成整頁重建、卡片抖動、重設捲動位置或中斷麥克風／取消觸控。離開畫面後停止 UI 更新與動畫。

### 操作、可及性與驗證

- [ ] 文字卡由最近定稿切到預覽，再回到定稿／結果時，主操作與取消仍保持可到達；長預覽、320dp 小視窗及 2.0 倍字體不遮擋結束／取消。TalkBack 可辨識區域與狀態，但不持續朗讀每個音量或文字回報。
- [x] 補上可控制回呼順序的行為測試，覆蓋無片段、文字修訂、等待定稿、無有效定稿、取消／離開後晚回呼、新舊段交錯、音量停止及單次提交；同時有原生整合測試證明正式資料接到正式畫面。
- [x] 執行相關單元、原生整合測試、建置及 lint；既有期限、定稿、取消、離開、就緒及結果不明行為保持通過。
- [ ] 留存無片段、已有預覽、等待定稿、取消及定稿結果的原生截圖，並記錄真實音量隨收音改變及停止後靜止的驗證證據；畫面與來源比對後列出有意差異。
- [ ] 實機驗證服務真實預覽、麥克風音量、停止／取消及 Windows 只收到轉錄定稿。交付自動測試、原生畫面與端到端結果，分別列出環境阻擋或未實測項目，不以 mock 波形當成真實音量驗收。
